Consultas SQL com parâmetros

Escreva a consulta, teste a conexão e rode sem sair do designer. Cada consulta vira uma tabela que os campos do relatório usam pelo nome.

  • Parâmetros como :inicio são detectados no SQL e aparecem num painel para preencher.
  • Várias consultas no mesmo relatório, como cabeçalho e itens.
  • Conexão com o banco configurada num arquivo database.ini.
SELECT numero, emissao, status, valor
  FROM pedidos
 WHERE cliente_id = :cliente
   AND emissao BETWEEN :inicio AND :fim

-- Parâmetros detectados: cliente, inicio, fim

Qualquer texto pode misturar palavras com campos do banco. O formato vem depois da barra e os totais vêm antes dos dois pontos.

  • {{Sum:Pedidos.Valor|C2}} soma a coluna. Também há Count, Avg, Min e Max.

Destaque condicional

Defina uma regra e o ReportForge aplica o estilo só onde ela vale. Pedido atrasado em vermelho, saldo zerado escondido, total acima da meta em negrito.

  • Regras como Value == "Atrasado", com ! para negar.
  • Muda cor do texto, preenchimento, estilo da fonte ou esconde o elemento.

Para ERPs

O relatório desenhado roda dentro do seu sistema.

O ReportForge.Engine abre o mesmo arquivo .rf.json salvo no designer e gera o PDF direto do seu código. O ERP pode mandar os próprios dados e variáveis, ou deixar o motor rodar o SQL do modelo.

0janelas abertas

O motor desenha a página sem depender do designer.

1modelo

O mesmo JSON serve para o designer e para o ERP.

3saídas

Arquivo PDF, bytes em memória, HTML ou CSV.

        Dúvidas
        
Perguntas frequentes

        
Não achou o que queria saber? Fale direto com o desenvolvedor.

      

      

        
Posso baixar o ReportForge?
O ReportForge já está pronto para uso, mas tem código fechado e não fica disponível para download público. Para usar no seu sistema ou ver funcionando, peça uma demonstração.

        
Como ele se conecta ao banco de dados?
Pela camada ReportForge.Data, com a conexão configurada num arquivo database.ini. Ela é separada do designer e do motor, então mudanças no acesso ao banco não mexem no restante.

        
Preciso abrir o designer para gerar um relatório?
Não. O ReportForge.Engine gera o PDF direto do seu código, a partir do mesmo arquivo salvo no designer.

        
O PDF sai igual à pré-visualização?
O motor segue a mesma lógica de bandas, grupos e quebras de página da pré-visualização. A tabela de dados é desenhada com tamanhos fixos, então pode haver diferenças pequenas de fonte em relação à tela.

        
Em que formato o relatório fica salvo?
Num arquivo .rf.json. Dá para versionar no Git junto com o seu sistema.

        
Em que ele roda?
Windows, com .NET 8 ou .NET 10. O designer é um app WinForms; o motor é uma biblioteca .NET.
